# SDK Size Comparisons

The [SDK size-analysis skill](../.claude/skills/sdk-size-analysis/SKILL.md) owns the
measurement workflow. From the standalone SDK root:

```sh
python3 .claude/skills/sdk-size-analysis/scripts/measure.py
```

See [the canonical measurement procedure](../.claude/skills/sdk-size-analysis/references/measurement.md)
for setup, controls, recovery, publication, matched comparisons and exceptional
signed/local-wired measurements. See
[interpretation rules](../.claude/skills/sdk-size-analysis/references/interpretation.md)
for attribution and experiment reasoning. This page remains as a stable link;
do not add a second measurement recipe here.
